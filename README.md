# 🌐 Site-languages

Welcome to **Site-languages**, a modern and interactive web project designed to help users discover and learn different programming languages and technologies (such as HTML, CSS, and PHP)!

---

## ✨ Features

* **Interactive Pages:** Dedicated sections for learning the basics of HTML, CSS, and PHP.
* **Clean Design:** Styled with a custom and responsive global CSS stylesheet.
* **Dynamic Content:** Powered by JavaScript for a smooth user experience.
* **Visual Assets:** Includes custom icons and illustrations (PNG & SVG formats)[cite: 1].
